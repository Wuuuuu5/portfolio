# Joseph Wu — Portfolio

My personal site: Computer Science @ University of Auckland, badminton player and coach.

- **Hero**: name swap to 吴卓熙 with a badminton rally
- **Kit bag tech stack**: unzip the bag and pull blocks out of a physics tower
- **My Badminton Setup**: a voxel player in a jump smash, with my real racket, kit and bag to hover

## Stack

Next.js · React · TypeScript · Tailwind CSS v4 · three.js (React Three Fiber) · matter-js · Lenis · Vercel

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:3000.
